# Nexus

Nexus 是 DeepSeek Harness 的实时语音管家插件，项目与包名为 `dsh-nexus`。

一个 Realtime 主 agent 与用户交流、观察全部工作会话并自主调度。挂断后继续工作，在同一个主会话输出文字。具体执行交给 Harness 工作会话。

首版设计已确认，当前完成前置调研与 Spec，尚无可安装实现。
