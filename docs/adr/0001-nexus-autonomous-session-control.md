# Nexus 自主操作全部 Harness 会话

项目名定为 Nexus，交付形态为独立的 DeepSeek Harness 插件。Realtime 模型作为唯一语音主管，负责实时交流和会话调度；首版覆盖 DeepSeek Harness，会话跨 Codex、Claude Code 等产品的能力留待后续。

Nexus 拥有完整操作权限，不设置 Nexus 特有的权限限制或人工审批。它可以直接使用、读取和调度全部 Harness 会话，包括用户手动创建的已有会话，无需逐个授权、交接归属或再次征求用户同意。选择这一方式是为了让 Nexus 成为统一管家，而非只管理自己创建的工作成员。

所有工作会话均进入 Nexus 的全局观察范围，工作结果应回到 Nexus，使其能够像主管读取 subagent 结果一样了解工作进展。观察范围不以是否由 Nexus 创建、是否曾显式交接为条件。结果回传后是否继续修复、审查、结束或报告阻塞，由 Nexus 根据用户目标和上下文自主判断，不在 Host 写死循环策略。

Harness 原生 subagent 的模型消息权限仅覆盖直接父子，不能单靠这一接口满足上述范围。后续设计需明确覆盖已有普通会话的控制方式。用户与 Nexus 同时操作时，用户的明确指令优先，采用 Harness 原生运行中引导，由 agent 理解并调整工作。首版不增加指令版本仲裁、意图分类或自动强制取消机制；详见用户指令优先设计记录。默认分工和挂断后的行为见 ADR 0002。
