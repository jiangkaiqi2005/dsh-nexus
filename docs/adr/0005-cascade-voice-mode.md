# 新增级联语音模式，与 Realtime 模式并存

Nexus 新增级联语音模式（语音识别 → 主管模型 → 语音合成），与原 Realtime 模式并存，由用户在全局设置中选择，下次接通时生效；默认为级联模式（2026-10-14 用户裁定）。实测主会话花费约 98% 来自每次回复重新计费的整段上下文，Realtime 模型缓存命中为零；级联模式的主管模型是带上下文缓存、原生结构化工具调用的文本 LLM，用以换取更低成本与更可靠的派活，代价是更高的语音延迟（首句目标 3 秒内）。本 ADR 取代 ADR 0001 中“Realtime 模型作为唯一语音主管”与 ADR 0002 中“不切换为另一个文本模型”的表述：原则改为同一主会话通话中与挂断后由所选语音模式的同一个主管模型承担。

级联模式的主管模型跟随 Harness 当前默认模型与推理强度（`agentDefaultModel`），不在 Nexus 另设模型选项。语音识别与合成在 Host 侧用 TS 按协议重新实现，不在运行时依赖栖语（Qiyu）；首版只接千问 3.1 系列，默认值照搬栖语：识别 `qwen-audio-3.1-asr-flash`（录完整段上传，单次上限 60 秒），合成 `qwen-audio-3.1-tts-flash` WS 推理（每条回复一个任务，逐句 `continue-task`，音色 `longanhuan_v3.1`），端点、型号、音色可配置，凭据复用 `DASHSCOPE_API_KEY`。

首版交互为点按说话：接通后点击开始、点击结束录音，识别文本直接作为用户发言；开始录音立即停止播放，并以句子粒度告知主管模型用户实际听到的部分；录音期间不播放任何语音，回复待录音结束后再播。插话不取消已在执行的工具调用，新发言按 Harness 原生运行中引导交付。识别失败或为空时提示未听清且不发起回合；合成中途失败则停止该条朗读，文字照常显示。免提连续通话与语音检测打断留待后续，点按的开始/结束即为其接缝。
