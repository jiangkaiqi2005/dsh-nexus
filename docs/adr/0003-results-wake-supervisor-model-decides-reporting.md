# 结果自动回流，Nexus 自主决定汇报

所有工作会话的结果自动投递 Nexus。主管正在处理时，在后续处理机会接收；空闲时唤醒处理。结果回流同时服务于后续调度和用户交流，不依赖用户主动查询。

继续派活、结束任务，以及是否、何时向用户汇报由 Nexus 根据目标和通话上下文判断。Host 不写死完成必播报、失败必插话等策略；语音层负责正常轮次和打断，挂断后主管仅输出文字。这与用户选择的模型自主判断原则一致。

Harness 原生 continuable 子会话已有直属父子通知与唤醒机制，Nexus 的全局观察还需覆盖普通顶层工作会话。具体事件接入和 Realtime 投递方式要对照安装版本实现并验证，不能把客户端状态事件或系统通知直接当模型已收到结果。依据见结果回流调研。
