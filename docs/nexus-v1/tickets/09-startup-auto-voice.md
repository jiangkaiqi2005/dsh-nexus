# 09：按默认关闭的选项每次启动自动接通一次

**要构建的行为：** 用户开启自动语音选项后，启动 Harness 无需手动拨号；每个启动周期只自动尝试一次，主动挂断后保持文字模式。

**阻塞于：** 08：挂断后继续文字调度并可手动再接通。

**状态：** draft，待确认拆分方案；本轮不执行。

**范围与约束：** 使用原生设置持久化。选项控制 Harness 启动后的语音行为，不涉及操作系统登录自启动 Harness。

- [ ] 新安装默认关闭自动语音；用户可在 Nexus 原生设置入口开启或关闭，设置能跨重启保存。
- [ ] 开启时等待 Host 与音频客户端就绪再尝试接通，实际状态与手动接通一致。
- [ ] 同一 Harness 进程启动周期只自动尝试一次；就绪回调重复、刷新、切换会话和重复挂载不导致再次开麦。
- [ ] 主动挂断后保持文字模式；手动再次接通仍可用，下一次真正重启 Harness 才有新的自动尝试周期。
- [ ] 启动时权限、设备或模型连接失败显示实际状态，并提供已有的手动接通入口；不循环自动抢麦或显示假接通。
- [ ] 关闭选项后新启动不自动采集麦克风；不创建操作系统自启动配置。
- [ ] 在真实启动与重启场景验证默认值、保存、一次尝试和挂断后的页面行为。
