## 为什么这样拆

- 01 包含横条、胶囊和侧栏入口，三者共用同一套状态映射，拆开会让同一套映射被写两遍。01 同时引入 primitives 和样式表基础设施。
- 02 只改设置页，复用 01 的基础设施；两张票改的是同一个文件，所以串行。
