# 01：通话横条、顶部胶囊与侧栏入口

**要构建的行为：** Nexus 主会话里，输入框上方显示一行与原生风格一致的通话横条；其他页面在通话中显示顶部正中的胶囊；侧栏入口换成 Nexus 图标，并带通话状态点。横条和胶囊共用同一套状态映射，包括状态点、流光文字、真实音量波形、录音计时、朗读跳动条、友好失败文案、Tooltip 里的原始码、「重试」，以及 4 秒后自动消失的临时提示。级联模式和 Realtime 模式共用这一套 UI。

**阻塞于：** 无。

**状态：** 实施及自验完成，评审中；待用户实机验收。ASR 原因按用户于 2026-10-15 的裁定作为例外，见[验证记录](../verification/01-call-bar-pill-sidebar.md)。

**范围与约束：** 依据 Spec 中「技术路线」「通话横条」「通话胶囊」「状态表达」「侧栏入口」「不变的部分」各节。

- 只改 [client.js](../../../client.js) 的渲染层和 `package.json` 的 `dsh.client.inject`。`Call` 的采集、播放、冲刷、回报逻辑，以及帧校验，保持原样；只在采集链和播放链上各接一个只读的 `AnalyserNode`。
- 引入 primitives 和样式表基础设施（`nx-` 前缀、只用 `--dsw-*` 变量、品牌混色），票 02 会复用它们。
- 不改 Host 代码，不改协议。

- [x] 主会话中未接通时，横条显示「语音未接通」和「接通语音」；接通后按状态表显示，Realtime 模式下没有录音按钮。
- [x] 录音时波形来自真实麦克风电平，计时格式为 `m:ss / 1:00`，剩 10 秒时变为警示色；朗读时的跳动条来自真实播放电平。
- [x] 按钮的显示文字和无障碍名称一致：「点按说话 / 结束录音 / 点按插话 / 接通语音 / 挂断 / 重试」。
- [x] 离开主会话后，顶部正中显示胶囊，点击能回到 Nexus；任何时刻最多一个 `[data-nexus-voice]`。
- [x] 失败码按 Spec 对照表显示友好文案，Tooltip 里含原始码；「没听清」「朗读失败」约 4 秒后回到空闲。ASR 缺凭据按下述用户裁定作为例外。
- [x] 侧栏入口显示图标，宽侧栏时附「Nexus」文字；通话状态点颜色符合 Spec；无障碍名称仍为「打开 Nexus」。
- [x] 现有测试全部通过（按旧名称定位的选择器已同步更新，断言的行为不降低），包括 Desktop 冒烟和独立安装测试；新增 Spec「测试决定」里与本票相关的断言。最终 148 项中 136 通过、0 失败、12 项真实端点 opt-in 跳过。
- [x] 按 Spec「原型基线」从 `506ba38` 移植方案 A 的部件和样式；只做 Spec 允许的那几类替换。
- [x] 在受控 Host 中，用 1360×860 视口、深浅两种主题，把真实 UI 驱动到 [baseline/](../baseline/) 的 8 个场景（横条在 7 个状态下，以及其他会话中录音时的胶囊），截图存档，并在验证记录中与基线并排对比；每处偏离都要写明原因。

失败映射及两类临时提示已实施并自验。用户于 2026-10-15 裁定接受例外：现有 Host 对 ASR 失败只下发不带 code 的 `unheard`，ASR 缺凭据在本票显示为「没听清」；其余失败码按对照表映射、Tooltip 含原始码。TTS 缺凭据已通过真实链路验证。本票不改 Host、协议或状态码。完整截图、偏离和实际命令结果见[验证记录](../verification/01-call-bar-pill-sidebar.md)。
