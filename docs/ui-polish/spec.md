# Nexus 前端打磨 Spec

状态：设计已由用户在 2026-10-15 的拷问中确认，尚未实施。依据：[领域词汇](../../CONTEXT.md)、[级联语音 Spec](../cascade-voice/spec.md)。这次只改前端，不新增领域概念，也不新增 ADR。视觉原型保存在本地一次性分支 `prototype/ui-polish`（`506ba38`，未推送），用户已经看过三套方案，裁定全部采用 A。进度见 [tickets](tickets.md)。

## 问题陈述

级联语音模式的功能已经完善，但前端很粗糙：

- 整个客户端 UI 是一个 [client.js](../../client.js)，全部用内联样式写成，和 Harness 原生界面不统一。深色模式下，边框靠 `currentColor` 勉强撑着。
- 状态只是一串拼接的文字，比如「已接通 Nexus · 识别中 (CODE)」：没有图标、动效或音量反馈，错误码直接露给用户。
- 通话中的右下角浮动框位置随意，可能压住其他会话的发送按钮。
- 设置页的常用项和端点、型号这类高级项混在一起，压缩说明是一大段文字。
- 侧栏入口只显示一个字母「N」，没有用上现成的 [icon.svg](../../icon.svg)。

## 解决方案

只改前端表现和交互，让 Nexus 看起来就是 Harness 自带的功能：

- 复用宿主的 `@deepseek-ai/dsh-client-ui-primitives` 组件；颜色、字号、圆角都只引用 `--dsw-*` 主题变量，深浅主题自动跟随。
- Nexus 的品牌青绿色（`#176b69`）只用于主操作按钮：接通、点按说话。
- 通话控件分两种形态：
  - 在 Nexus 主会话里，输入框上方显示一行**通话横条**；
  - 在其他会话、设置等任何其他页面，屏幕顶部正中显示一个**通话胶囊**。
- 设置页按原生设置页的行式布局分三组；侧栏入口换成 Nexus 图标，并显示通话状态点。

Host 侧代码、上下行协议和状态码一概不变。

## 原型基线（防漂移）

用户已认可原型方案 A 的效果（2026-10-15），因此原型就是实现蓝本和视觉验收基线；本 Spec 的文字没写到的视觉细节，一律以原型为准。

- **代码蓝本**：`git show 506ba38:prototype/ui-polish/client.prototype.js` 中方案 A 用到的全部部件和样式。
  - 部件：`describe`、`Status`、`Bars`、`RecordButton`、`HangupButton`、`RetryButton`、`ConnectButton`、`ModeTag`、`NexusMark`、`HangupIcon`、`BarA`、`PillA`、`SidebarEntry`，设置页（票 02）为 `Settings`、`Row`、`Disclosure`。
  - 样式：样式表中的通用段、`/* A */`、`/* sidebar */`、`/* settings */` 各段。
  - 结构、DOM 顺序、`nx-` 类名、尺寸、间距、所用 token、文案和图标都按原样移植。只能做这几类替换：假状态 `store` 换成真实的 `Call` 状态；假电平换成 `AnalyserNode` 读到的真实电平；假计时换成真实的录音开始时间；假动作换成 `Call` 的真实方法。
  - 原型里只为原型存在的东西不移植：方案 B、C，`Switcher`，`localStorage` 状态。
- **视觉基线**：[baseline/](baseline/) 里有横条在 7 个状态下的截图，以及其他会话里录音中的胶囊截图，深浅主题各一套；截图均由 Harness 在 1360×860 下渲染。实现完成后，要在受控 Host 中把真实 UI 驱动到同样的状态、用同样的视口截图，与基线并排对比。
- **偏离规则**：凡是和蓝本或基线不一致的地方，都必须在验证记录中逐条列出：偏离了什么、原因、对照截图。没有列出的偏离，一律当作缺陷处理。可以接受的偏离只有两类：真实数据和假数据造成的差异（比如计时数字、波形形状），以及修复原型自身的缺陷。

## 实现决定

### 技术路线

- 保持「单个 `client.js`、不加构建步骤」。原因是票 06 的独立打包、安装流程和 Desktop 冒烟测试都建立在 `client.js` 原样发布之上。
- 用 `require('@deepseek-ai/dsh-client-ui-primitives')` 复用这些组件和图标：`Button`、`Switch`、`SegmentedControl`、`StateDot`、`TextShimmer`、`Tooltip`、`IconMicrophoneOutline*`、`IconStopFill*`、`IconChevronDownOutline*`、`IconRefreshOutline*`、`IconInfoOutline*`。`package.json` 的 `dsh.client.inject` 补上 `@deepseek-ai/dsh-client-ui-primitives`，宿主自带的语音输入插件也是这样声明的。
- 自定义样式统一放进一段注入的样式表，类名用 `nx-` 前缀，只引用 `--dsw-*` 变量，不再写内联样式。品牌强调色在样式表里由 `#176b69` 和 `--dsw-alias-label-primary` 混色得到，这样深浅主题下都有足够对比度，不需要判断当前主题。
- 挂断图标原生组件库里没有，自带一个 SVG。
- 文案中英两份，沿用现有的 `ctx.locale.register('nexus', …)`。

### 通话横条（Nexus 主会话，`conversation.input.dock`）

- 只在 Nexus 主会话中显示，左右边距和输入框卡片对齐，高 44px，一行排列：Nexus 图标、状态、波形或计时、空白、模式标签（只在接通后显示）、主操作、挂断。
- 未接通时显示「语音未接通」，主操作是品牌色的「接通语音」按钮，不显示挂断。
- 级联模式接通后，主操作是品牌色的「点按说话」；录音时变成描边红色的「结束录音」，朗读时变成「点按插话」，识别中禁用。Realtime 模式下不显示这个按钮。
- 挂断是一个图标按钮，悬停时变为红色调，带「挂断」Tooltip，无障碍名称为「挂断」。

### 通话胶囊（其他页面，`shell.overlay`）

- 只要通话没有处于未接通状态，并且当前屏幕上没有 Nexus 主会话的横条，就在顶部正中显示胶囊：Nexus 图标加紧凑状态（录音时带计时）、迷你波形或朗读条、圆形录音按钮（仅级联）、挂断。
- 点击图标和状态区域会打开 Nexus 主会话。
- 任何时刻最多只有一个通话控件（横条或胶囊）可见，带 `data-nexus-voice` 的元素也就最多一个。这个不变量和现在一样。

### 状态表达

| 状态 | 表达 |
| --- | --- |
| 正在接通 | 加载中的 `StateDot` 加流光文字「正在接通…」 |
| 已接通、空闲 | 绿点，文字为「已接通 · 点按说话」；Realtime 下为「通话中 · 自动听写」 |
| 录音中 | 红点、「正在听」、真实麦克风音量的波形、`0:12 / 1:00`；剩 10 秒时计时变为警示色 |
| 识别中、思考中 | 流光文字 |
| 朗读中 | 「正在朗读」加真实播放音量的跳动条 |
| 没听清、朗读失败 | 琥珀色提示，4 秒后自动回到空闲；期间一有新的活动就立刻被替换 |
| 接通失败、麦克风问题 | 红色说明、ⓘ Tooltip（提示加原始码）、「重试」按钮，一直保留到用户点重试或挂断 |

- 波形用 `AnalyserNode` 读取客户端已有的采集链；朗读条读取播放链的输出电平。两者都只在前端完成，不改协议。
- 失败文案对照：

| 错误码 | 主文案 | Tooltip 提示 |
| --- | --- | --- |
| `CALL_BUSY` | 另一个窗口正在通话 | 先在那个窗口挂断 |
| `CALL_CLOSED`、`CONNECTION_CLOSED` | 通话已中断 | 与 Host 的连接断开 |
| `CONNECTION_FAILED`、`TIMEOUT` | 连不上语音服务 | 检查网络或端点设置 |
| `*CREDENTIAL_MISSING`（含 ASR、TTS 前缀） | 未配置 DashScope 凭据 | 在 Host 配置 `DASHSCOPE_API_KEY` |
| `mic-denied` | 麦克风权限被拒绝 | 在浏览器或系统设置中允许后重试 |
| `no-device` | 没有可用的麦克风 | 检查输入设备 |
| `mic-failed` | 麦克风无法使用 | 检查输入设备 |
| `playback-blocked` | 浏览器暂不允许播放声音 | 点「重试」即可 |
| 识别失败（`ASR_*`，凭据缺失除外） | 没听清，请再说一次 | — |
| 合成失败（`TTS_*`，凭据缺失除外） | 朗读失败，文字已保留 | — |
| 其他 | 通话失败 | 显示原始码 |

### 侧栏入口（`sidebar.footer.action`）

- 显示 Nexus 图标；宽侧栏时加「Nexus」文字。窄侧栏时用 Tooltip 显示「打开 Nexus」，接通后再附上当前状态。
- 通话中，图标右上角显示状态点：接通为绿色，录音中为红色闪烁，出错为琥珀色。
- 无障碍名称保持「打开 Nexus」。

### 设置页（`settings.section`）

- 照原生设置行：左边是 14px 标题加 12px 说明，右边是控件，行与行之间用 `--dsw-alias-border-l2` 分隔线隔开；顶部是 Nexus 图标加一句介绍。
- **通话**：
  - 语音模式用 `SegmentedControl`（级联、Realtime），说明为下一次接通生效；
  - 启动后自动接通用 `Switch`，说明为下一次启动 Harness 生效。
- **语音服务**：
  - 合成音色常驻显示；
  - 「高级：识别与合成端点、型号」默认折叠，展开后是识别端点、识别型号、合成端点、合成型号，端点和型号用等宽字体。
- **上下文压缩**：
  - 压缩预算、摘要模型、摘要思考强度三项（原型里漏了摘要思考强度，正式实现时必须保留）；
  - 现在那一长段说明拆成一句短说明，其余收进默认折叠的「了解更多」。
- 保存语义保持现状，包括失焦或回车提交、写入失败时提示、表单不可写时禁用；思考强度的可选项逻辑和默认摘要模型常量也一并保留。

### 不变的部分

- `Call` 类的采集、播放、冲刷、回报逻辑，以及上下行帧的校验，原样保留。本次只替换渲染层，另外在采集和播放链上各接一个只读的电平分析节点。
- 测试属性原样保留：`data-nexus-voice`、`data-state`、`data-activity`、`data-played-samples`、`data-flushes`、`data-discarded-samples`。

## 测试决定

- 沿用现有边界：受控 Harness Host 加 Playwright，只断言外部可见的行为。不为样式另设单元测试。
- 无障碍名称和显示文字保持一致。现有测试里按旧名称定位的地方要跟着改，比如「开始录音」改为「点按说话」，设置项名称也一样；断言的行为不能降低。
- 新增或改写的断言：
  - 主会话里只有横条、其他页面只有胶囊，任何时刻最多一个 `[data-nexus-voice]`；
  - 点击胶囊能回到 Nexus；
  - 失败时显示友好文案，Tooltip 里含原始码；
  - 「没听清」约 4 秒后回到空闲；
  - 设置页三组可见，展开「高级」后能看到端点和型号，修改后能保存。
- 现有全部测试保持通过，包括 Desktop 冒烟和独立安装测试。
- 深浅两种主题各截一轮图，存档在验证记录里；最后由用户实机看一遍才算完成。

## 范围之外

- 录音快捷键（例如空格键按住说话）。
- Host 侧代码、协议、状态码的任何改动。
- 引入构建步骤或 CSS Modules。
- 原型里的 B（通话卡片）、C（工具栏）两套方案。
- 新的领域词汇和 ADR。
