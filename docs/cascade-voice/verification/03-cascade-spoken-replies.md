# 票 03 验证记录

本票基线：`f53ff2a6eda9f76be7cde2a11441b74bc9c59017`。范围为级联通话接通、主管回复逐句合成与播放、挂断和单条合成失败；不包含录音识别、插话或录音期间缓存。

## 实现

级联接通复用现有单客户端媒体授权与播放准备，不打开主管或合成连接。主管轮次、工具执行、工作结果回流、默认模型路由和原生持久化仍共用票 02 的实现。级联通话提示写明文本输入、短句口语及逐句朗读，不复用 Realtime 的直接听音频描述；挂断后恢复文字提示。

Host 在每条有文字的回复中按中文和英文句末及换行切句，第一句完整后才解析现有凭据引用、建立 DashScope WS 推理任务。先 `run-task`，等待 `task-started`，逐句 `continue-task`，最后 `finish-task`，同任务使用同一 `task_id`。默认端点、型号和音色与 Spec 一致，格式固定 PCM16、24 kHz、单声道。端点、型号和音色可以在 Nexus 设置中修改。二进制帧直接进入既有浏览器 PCM 播放；不假定每句只对应一个音频帧。

回复的合成任务按生成次序排队，文字监听同步入队，主管和工具不等待合成或播放。任务结束后关闭连接。挂断取消所有朗读任务、清空音频并结束媒体占用，主管和已发工具继续。失败只取消当前任务并停止当前朗读，保留原生全文、通话仍接通、下一条回复可建立新任务；下行只使用固定失败码，不转发可能回显凭据的提供方错误正文。

“思考中”和“朗读中”与通话接通状态分开。播放节点尚未结束时优先显示朗读；前一条合成任务结束、下一条主管仍生成时显示思考。工具调用内容不进入朗读队列。

## 验收边界与证据

`tests/cascade-spoken.test.mjs` 在隔离的官方 Harness Host 中注册外部 LLM 测试提供方及默认模型，通过真实 Edge 的 Nexus 通话流和主会话输入操作；合成依赖是本地受控 WS。断言原生持久化记录、实际端点请求、浏览器下行帧及状态，没有替换主管内部组件。

- 首句闸门：第一句前显示思考；主管仍被第二句输出闸门阻塞时，浏览器收到第一句 PCM 并显示朗读。挂断发出取消、后续完整文字及下一轮文字保留，且没有新的合成请求。默认型号、音色、PCM 参数与 Host 握手鉴权均有断言。
- 完整句子：中英文句末、换行、无句末尾文本按顺序朗读；端点每句发送多个 binary；单条 TTS 中途失败仍保留全文、显示 `TTS_SYNTHESIS_FAILED` 并保持接通；修改型号和音色后的下一条任务使用保存值。
- 原生文本块：回复只返回最终 `block-end` 时也会朗读；同一回复混合最终文本块及流式文本块时，按块索引补齐未通知的尾部，两句恰好各朗读一次，不重读已有 delta。
- 后台工作：原生工作结果由主管生成的汇报被朗读；原生工具调用不朗读。已经执行的慢工具在挂断后返回真实结果并由同一主管文字续答；原生工作会话也在挂断后完成并回流纯文字汇报。
- 跨回复顺序与状态：受控端点保留第一条合成任务，主管工具和下一模型步骤仍执行；前条音频播放时显示朗读，前条结束而下条模型仍生成时显示思考，之后第二条回复按顺序朗读。
- 凭据：浏览器实际 WebSocket 下行及主管流里没有测试凭据；提供方故意在失败正文中回显的测试凭据也不会下发。
- 真实端点用例只在 `NEXUS_REAL_VOICE=1` 时执行。默认跳过，未读取真实凭据、修改生产 profile 或调用付费语音端点。

## 失败调查

初始夹具缺少既有必填 `endpoint`，Host 未激活 Nexus，日志 `03-red.log`、`03-red-valid.log`、`03-first-green.log`；这些不是首句行为的有效 red。补齐隔离夹具配置后首句验收通过。

跨回复专项首次失败是夹具的 `text-delta` 写 `QUEUE-FIRST。`、`block-end` 写 `正在查询。` 不一致；浏览器状态和合成顺序检查已通过，但最后原生记录断言失败。把夹具的最终文本改成与 delta 一致后，`03-queued-final.log` 通过。没有改变产品以适配错误夹具。

最终文本块用例先在 `.scratch/cascade-voice/03-block-only-red.log` 失败：浏览器主会话已有 `TEXT ONLY.` 全文，但一直没有收到该条合成任务。此前只通知 `text-delta`，遗漏 Harness 合法的仅最终文本块回复。补齐按原生文本块索引跟踪已通知前缀、在 `block-end` 通知余下文本后，最终专项通过，并以混合文本块断言每句只朗读一次。

首次全套日志 `03-full.log`：117 项，103 通过、13 跳过、1 失败，415.046 秒。此运行期间产品仍有修改，不能作为冻结版本门槛。失败项为既有 Realtime“新建工作会话”用例，发生在 `openNexus`：DOM 停留在原生空白新会话、没有 Nexus 入口或通话条；Host 主管 idle、零轮。原因未定位，不能据此判定夹具或产品问题。原用例单独重跑 `03-realtime-create-diagnosis.log` 通过，13.254 秒；没有产品改动规避该失败。最终冻结版本另行运行完整套件。
