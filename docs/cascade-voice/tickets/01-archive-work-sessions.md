# 01：Nexus 用原生归档清理工作会话

**要构建的行为：** 用户要求 Nexus 清理或归档某个工作会话时，Nexus 调用 Harness 原生的会话归档，并停止该会话正在进行的活动。原生界面里这个会话显示为已归档，之后也可以撤销。用户如果说“删除”，Nexus 会说明原生只支持归档。Nexus 不再要求工作会话删除自己或其他会话的数据。

**阻塞于：** 无，可以立即开始。

**状态：** 已完成（2026-10-14），标准与规格两轴最终均 approve，无未决评审问题。

**验证记录：** [本票实施、检查与评审](../verification/01-archive-work-sessions.md)。

**范围与约束：** 依据 [级联语音 Spec](../spec.md) 中“归档工作会话”这一节的实现决定，并遵守 ADR 0001（Nexus 拥有完整权限，不另加限制）。本票只新增归档这一项能力，外加两条提示词说明。以下内容用户已裁定沿用 Harness 原生行为，本票不做：删除会话、限制步数、检测重复调用、截断工具结果、改动用量记录。票 02 也会改主管提示词，两票不要同时实施。

- [x] 主管工具集里多了一个归档工作会话的工具。用它归档一个运行中的工作会话后，原生界面显示该会话已归档，后台活动也已停止。
- [x] 尝试归档 Nexus 主会话本身时会被拒绝；归档一个不存在的会话时，如实返回错误。
- [x] 主管提示词写明：清理会话要用归档工具，不要让工作会话删除数据；用户要求删除时，告诉用户原生只能归档。
- [x] 现有的派活、结果回流和压缩测试全部保持通过。

**Spec 对照：** 用户故事 42–46；“归档工作会话”实现决定；测试表中的“归档工具”一项。
